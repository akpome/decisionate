# Share dashboards and retain evidence

Sharing a dashboard, saving a dashboard PDF, exporting decisions and saving a
report snapshot are separate operations. Choose the one that matches the audience
and whether you need a live view or frozen evidence.

## Public dashboard links

Use authorized sharing controls only after checking the workspace, dataset,
metrics, mappings and filters. A shared dashboard can be opened by people who
have its link under the current sharing policy. Do not include sensitive segments
or assume a public link has the same boundary as an authenticated workspace page.

Stop sharing when the audience or intended purpose changes. If a shared view
looks different, compare the dataset, selected metrics, time window, grouping,
mapping and dimension filter before attributing the difference to the source.
Refresh or republish only through the application's supported controls.

## PDFs and exports

Save PDF captures the supported dashboard view; verify its visible period and
selection before distributing it. Decision exports contain decision records,
not a complete copy of every raw dataset. Available export and deletion actions
depend on the authenticated role.

A saved report snapshot preserves its generated analysis and evidence, rather
than becoming a live chart that silently changes after every sync. Recalculate
and save a new snapshot for a new period or selection.

## Weekly email is not the same export

Weekly delivery builds a completed-week review from the selected template. It
does not email the dashboard's PDF or embed the app's indexed chart in the
current template. Confirm recipients and filters separately from public sharing;
turning off a shared link does not itself change weekly email recipients.
