# Connector Demo Datasets

These deterministic CSV fixtures contain 100 rows each for testing dashboard
mapping, aggregation, insights, forecasts, reports, and decisions.

Included connectors:

- Google Analytics
- Stripe
- Shopify
- QuickBooks
- FreshBooks
- HubSpot
- Meta Ads

The Google Drive, OneDrive, PostgreSQL, MySQL, and SQL Server fixtures were
intentionally excluded. These files are connector-shaped test data, not live
connector responses or credentials. Upload a CSV to test the analytics flow,
or use the matching column names when validating a connector adapter.
